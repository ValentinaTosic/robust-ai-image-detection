## Project Description

AI-generated image detectors are commonly evaluated on image generators that are represented in the training data. Such evaluation may overestimate how well a model performs on images generated by previously unseen models.

This project investigates the **generalization of AI-image detectors to unseen generative models**. We compare several approaches for distinguishing real images from AI-generated images and evaluate how their performance changes when an entire image generator is excluded from training.

The project includes both standard evaluation, where all selected generators are represented in the training data, and **Leave-One-Generator-Out (LOGO)** evaluation, where one generator is completely held out and used only for testing.

The evaluated approaches include:

- A CNN trained from scratch
- ImageNet-pretrained ResNet18
- A pretrained Vision Transformer (ViT-Small)
- Frequency-domain classifiers based on FFT features

The project also includes an explainability analysis using Grad-CAM, attention rollout, and frequency-domain feature contributions.

## Dataset

We use the [Tiny-GenImage dataset](https://www.kaggle.com/datasets/yangsangtai/tiny-genimage), a smaller version of the GenImage benchmark.

The dataset contains:

- **Real images** from ImageNet
- **AI-generated images** from multiple generative models

For this project, seven AI generators are used:

- BigGAN
- GLIDE
- VQDM
- Stable Diffusion v1.5
- ADM
- Midjourney
- Wukong

Stable Diffusion v1.4 is part of the original GenImage benchmark but is not available in the dataset version used in this project.

The experimental subset contains **14,000 images in total**, consisting of 7,000 real and 7,000 AI-generated images.

All images are standardized to a common format and resized to `224 × 224` before being used for model training and evaluation.

## Methodology

The experiments investigate two main settings:

### Standard Evaluation

Models are trained and tested with all seven generators represented in the dataset.

### Unseen-Generator Evaluation

The LOGO protocol is used to evaluate whether models can detect images generated by a model that was not present during training.

In addition to holding out each generator individually, an additional experiment jointly holds out Stable Diffusion v1.5 and Wukong.

The models are compared using standard classification metrics, including accuracy, precision, recall, F1-score, and ROC-AUC.

Detailed experimental procedures, visualizations, statistical analysis, and explainability results are provided in the project notebooks.

## Main Results

On the standard evaluation, the pretrained models achieved the strongest overall performance, with ViT-Small obtaining the highest F1-score and ROC-AUC.

The LOGO experiments show that **generalization depends strongly on the unseen generator**. Some generators remain relatively easy to detect when excluded from training, while others result in a substantial decrease in performance.

Overall, ViT-Small and ResNet18 provide the strongest absolute performance across most unseen-generator experiments. The frequency-domain approaches can perform well for particular generator shifts, but their advantage is not consistent across all generators.

The experiments therefore indicate that **strong performance on seen generators does not necessarily imply robust generalization to unseen generative models**.
