# Data

The dataset is not committed to this repository because of its size.
This file describes the dataset source, local setup, and directory structure
expected by the project.

## Source dataset

We use the [Tiny-GenImage dataset](https://www.kaggle.com/datasets/yangsangtai/tiny-genimage), a smaller version of the GenImage benchmark designed for more manageable experimentation.

The dataset contains:

- **Real images:** ImageNet images
- **AI-generated images:** images generated by BigGAN, GLIDE, VQDM,
  Stable Diffusion v1.5, ADM, Midjourney, and Wukong

Stable Diffusion v1.4 is part of the original GenImage benchmark, but it is
not included in the dataset version used in this project.

For more information about the original benchmark, see the
[GenImage paper](https://arxiv.org/abs/2306.08571).

## Sample sizes

The active sample size is configured in `configs/experiments.yaml`.

- **small** (default): ~800–1,000 images per generator + matched real images
- **large** (once compute is confirmed): 3,000–5,000 images per generator

The current configuration uses:

- **1,000 AI images per generator**
- **7,000 AI images in total**
- **7,000 real images**
- **14,000 images in total**

The real images are sampled from the available real-image pools and are
treated as a single `real` source rather than being associated with a
specific generator.

## Local setup

The raw dataset is stored outside the repository and is read directly from
disk during dataset preparation.

Set the local dataset location in:

`configs/experiments.yaml`

under:

```yaml
paths:
  raw_data_root: "path/to/dataset"
```

## Expected local folder layout

After running `notebooks/01_dataset_preparation.ipynb`, this directory should look like:

```
data/
├── processed/                 # standardized images (resized, RGB, metadata stripped, re-encoded)
│   ├── ai/                    
│   └── real/
└── dataset.csv                 # filename | label | generator | split | source_path — built by 01_dataset_preparation
```
