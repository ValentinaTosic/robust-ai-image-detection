# Models

Trained model checkpoints (`*.pth`, `*.pt`, `*.ckpt`) are **not** committed to this repo — see
`.gitignore`. Notebooks save checkpoints here locally as they train (e.g.
`models/resnet18_seen.pth`, `models/vit_logo_midjourney.pth`).

If checkpoints need to be shared between team members or submitted, upload them externally (e.g. Google
Drive, Hugging Face) and link them from the top-level `README.md` under "Pretrained models".
